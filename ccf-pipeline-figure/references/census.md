# How many conceptual figures a paper actually has

## Method, so the numbers can be argued with

- **30 award-winning papers**, every figure pulled with the authors' captions.
- ⚠ **This census was measured on the roster as it stood BEFORE the recency recut.** The
  roster is now 42 papers, all submitted 2024-05 or later; a few papers counted here
  (Genie, VAR, Vision Transformers Need Registers, Generative Image Dynamics, Stealing
  Part of a Production LM) were later dropped for being too old. The distribution has not
  been recomputed on the new roster, so treat these figures as a measurement of
  *award-paper practice around 2023-2025*, not of the current corpus exactly.
- A vision pass opened the first 8 real figures of each paper — **192 images** — and classified each as conceptual / data_plot / hybrid / qualitative / table_image.
- ⚠ The cut at 8 is a **stated convention, not a measurement**: arXiv's HTML carries no page number, so 'main body' cannot be measured directly. Full totals are reported beside it.
- ⚠ Two papers in the roster carry **zero figures of any kind** and are absent from the denominator, which is 28, not 30.
